🦫 Beaverish

High-throughput, protocol-agnostic daemon & Model Context Protocol (MCP) server for binary event contracts and order-book prediction markets on Somnia EVM.

Go 1.25 Somnia Chain ID: 50312 Model Context Protocol (MCP) Zero SaaS Dependency

⚡ One-Command Installation

Install Beaverish directly from source in a single command:

curl -sSL https://raw.githubusercontent.com/nathfavour/beaverish/main/install.sh | sh

Or run via GitHub Container Registry (GHCR):

docker run -i --rm ghcr.io/nathfavour/beaverish:latest --mcp

🤖 First-Class MCP Integration

Beaverish provides stdio JSON-RPC 2.0 tools for Claude Code, Codex, Antigravity, and Cursor:

  • get_markets: Fetch active prediction event contracts & orderbook depths.
  • evaluate_market: Evaluate parity edge arbitrage (< 1.00) & momentum signals.
  • execute_order: Sign and dispatch EVM orders on Somnia testnet.
  • sweep_settlements: Autonomous payout redemption for resolved positions.
  • get_account_status: Collateral balance, native balance, and open position tracker.
